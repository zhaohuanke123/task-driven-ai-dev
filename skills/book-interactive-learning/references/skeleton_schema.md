# 书籍骨架格式规范

## 核心原则

**每个论点必须带原文行号**

没有行号的骨架是糊弄式总结，无法回到原文验证。

## 骨架文件结构

```markdown
# 第N章 章节标题

## 核心论点

### 论点1：[一句话概括]
- 原文位置：行 XXX-XXX
- 关键内容：[具体描述]
- 关联概念：[相关概念名]

### 论点2：[一句话概括]
- 原文位置：行 XXX-XXX
- 关键内容：[具体描述]
- 反常识点：[如果有]

## 可跳过内容

### 实验细节
- 位置：行 XXX-XXX
- 原因：对理解核心概念无帮助，只需知道结论

### 背景介绍
- 位置：行 XXX-XXX
- 原因：与正文重合90%，冗余

## 本章与全书的关系

- 前置章节：[需要先理解哪些章节]
- 后续章节：[为哪些章节铺垫]
- 核心贡献：[本章在全书中解决什么问题]
```

## 示例：《思考，快与慢》第5章

```markdown
# 第5章 认知放松

## 核心论点

### 论点1：认知放松让人更容易相信
- 原文位置：行 491-503
- 关键内容：又累又饿的保释官容易否定保释申请。严肃的职业判断被血糖决定。
- 反常识点：你的"深思熟虑"可能只是今天没吃午饭。

### 论点2：重复曝光效应
- 原文位置：行 521-535
- 关键内容：反复接触某个刺激会让人产生好感，即使没有意识到。
- 关联概念：系统1的"熟悉即安全"机制

### 论点3：真相错觉
- 原文位置：行 548-562
- 关键内容：如果某个陈述容易理解，人们倾向于相信它是真的。
- 反常识点：清晰表达 ≠ 正确观点

## 可跳过内容

### 保释官实验详细数据
- 位置：行 495-498
- 原因：只需知道结论"饥饿影响判断"，数据细节不重要

### 重复曝光实验历史
- 位置：行 523-530
- 原因：历史背景，不影响理解核心机制

## 本章与全书的关系

- 前置章节：第1-3章（系统1/2基础）
- 后续章节：第11章（锚定效应）
- 核心贡献：揭示系统1的"认知放松"机制，解释为什么我们容易被欺骗
```

## 骨架生成流程

### Step 1：并行读取

发送 4 个 agent，每个负责不同部分：

| Agent | 负责范围 | 任务 |
|-------|---------|------|
| Agent 1 | 前1/4章节 | 提取核心论点 + 行号 |
| Agent 2 | 第2个1/4 | 提取核心论点 + 行号 |
| Agent 3 | 第3个1/4 | 提取核心论点 + 行号 |
| Agent 4 | 最后1/4 | 提取核心论点 + 行号 |

### Step 2：合并骨架

将 4 个 agent 的产出合并，统一格式。

### Step 3：标注可跳过

识别：
- 实验细节（只保留结论）
- 背景介绍（与正文重合的）
- 附录内容（冗余的）

### Step 4：建立关联

标注每章与全书其他章节的关系。

## 骨架质量检查

| 检查项 | 标准 | 不合格示例 |
|-------|------|-----------|
| 行号 | 每个论点必须有 | "认知放松影响判断"（无行号） |
| 一句话概括 | 简洁明了 | "这一章讲了好多东西" |
| 反常识点 | 标注出来 | 只写"这一章很重要" |
| 可跳过标注 | 有理由 | "这部分可以跳过"（无理由） |

## 注意事项

- 骨架长度：原书的 1/3 ~ 1/4
- 保留：核心论点 + 反常识点 + 关联关系
- 删除：实验细节 + 背景介绍 + 冗余附录
- 必须有：每个论点的原文行号
