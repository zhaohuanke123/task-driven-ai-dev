# 学习地图格式规范

## 核心原则

**按用户盲点重排，不是复制原书目录**

学习地图是基于诊断结果 + 骨架分析，为用户定制的路径。

---

## 学习地图结构

```markdown
# 《书名》学习地图

## 诊断摘要

### 用户盲点（按优先级）
1. [盲点1] - 来自诊断Q3
2. [盲点2] - 来自诊断Q1
3. [盲点3] - 来自诊断Q4

### 已掌握内容
- [概念1] - 诊断显示已理解
- [概念2] - 诊断显示已理解

---

## 学习单元

### 单元1：[针对最大盲点的主题]

**来源**：原书 Ch X

**核心问题**：[这个单元解决什么问题]

**为什么第一个学**：诊断显示这是你最大的盲点

**预计时间**：XX 分钟

**关联单元**：前置无，后续 [单元3]

---

### 单元2：[第二个盲点主题]

**来源**：原书 Ch Y

**核心问题**：[这个单元解决什么问题]

**为什么第二个学**：与单元1形成互补，加深理解

**预计时间**：XX 分钟

**关联单元**：前置 [单元1]，后续 [单元4]

---

## 跳过内容

| 章节 | 原因 | 备注 |
|-----|------|------|
| Ch 1 | 已掌握基础概念 | 诊断Q1显示理解正确 |
| Ch 4-5 | 实验细节 | 结论已在骨架中，无需深究 |
| 附录 | 与正文重合90% | 冗余 |

---

## 学习路径图

```
诊断盲点
    ↓
单元1：[最大盲点] ← 从 Ch X 提取
    ↓
单元2：[第二盲点] ← 从 Ch Y 提取
    ↓
单元3：[补充背景] ← 从 Ch Z 提取
    ↓
综合应用
```

---

## 后续更新

学习过程中，如果发现新的盲点，在地图中插入新单元：

```markdown
### 单元2b：[新发现的盲点]

**来源**：单元2学习中发现

**触发原因**：用户在费曼检验中暴露新盲点

**插入位置**：单元2 之后，单元3 之前
```
