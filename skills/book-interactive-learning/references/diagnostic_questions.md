# 诊断题设计指南

## 设计原则

诊断题不是考试，是探测盲点。目标是找出"你以为懂了其实没懂"的地方。

### 四道题的分工

| 题号 | 目的 | 设计方向 |
|-----|------|---------|
| Q1 | 基础概念理解 | 问核心定义，看是否有误解 |
| Q2 | 应用场景判断 | 问实际案例，看能否正确应用 |
| Q3 | 反常识探测 | 问容易犯错的地方，暴露盲点 |
| Q4 | 个人痛点定位 | 问具体困境，定制学习路径 |

### 好的诊断题特征

1. **不考记忆** - 不问"第3章讲了什么"，问"你怎么理解XX概念"
2. **允许犯错** - 错误回答比正确回答更有价值（暴露盲点）
3. **有陷阱** - 设计常见误解，看用户是否掉进去
4. **关联实际** - 问用户的具体场景，而非抽象理论

### 示例

#### 《思考，快与慢》

```
Q1: 你对系统 1 / 系统 2 的理解是什么？
→ 探测：是否把系统2当成"更好"（常见误解）

Q2: 什么时候你会用"直觉"做决定？什么时候会"深思熟虑"？
→ 探测：是否意识到两种模式的切换机制

Q3: 球拍和球总价 1.10 美元，球拍比球贵 1 美元，球多少钱？
→ 探测：系统1是否自动蹦出错误答案（10美分）

Q4: 你最近做过什么重要决定？后悔吗？为什么？
→ 探测：决策盲点，定制学习重点
```

#### 《原子习惯》

```
Q1: 你认为习惯形成的核心机制是什么？
→ 探测：是否理解"提示-渴望-反应-奖励"循环

Q2: 为什么"靠意志力坚持"往往失败？
→ 探测：是否理解意志力是消耗品，不是习惯引擎

Q3: 你有没有"想养成但一直失败"的习惯？分析原因？
→ 探测：是否把失败归因于"不够努力"（错误归因）

Q4: 你想成为什么样的人？现在的习惯和这个身份一致吗？
→ 探测：身份认同与习惯的关系
```

#### 《非暴力沟通》

```
Q1: 当别人批评你时，你的第一反应是什么？
→ 探测：是否进入防御/反击模式（常见反应）

Q2: "你总是迟到"这句话，你听到的是什么？
→ 探测：是否能区分观察vs评论

Q3: 你最近一次生气是因为什么？对方做了什么？
→ 探测：是否能找到背后的未满足需求

Q4: 你最想改善的一段关系是什么？卡在哪里？
→ 探测：定制学习重点
```

## 从回答中诊断盲点

### 诊断模板

```markdown
## 回答分析

### Q1 回答：[用户回答]
- 理解程度：[完全正确 / 部分正确 / 有误解]
- 暴露盲点：[具体描述]

### Q2 回答：[用户回答]
...

## 综合诊断

### 主要盲点（按优先级）
1. [盲点1] - 来自Q3回答
2. [盲点2] - 来自Q1回答
3. [盲点3] - 来自Q4回答

### 这本书对你的价值
- 最需要学的章节：[具体章节]
- 可以跳过的内容：[具体章节]
```

## 注意事项

- 诊断题数量：4道（不多不少，覆盖全面）
- 时间控制：5-10分钟完成
- 不评判对错：只记录理解状态
- 错误更有价值：暴露盲点是诊断的核心目的
